# Md Tasnemul Hossain Chowdhury — Portfolio

Responsive static portfolio made with HTML, CSS, and vanilla JavaScript for the GitHub Pages repository `nihalth324/md.tasnemulhossain`.

## Files and assets

- `index.html` — page content and metadata
- `styles.css` — visual system and responsive layout
- `script.js` — mobile navigation, project filters, and scroll behavior
- `album.html` — separate photography album page
- `album.css` — responsive masonry-style gallery and full-screen viewer
- `album.js` — photo category filters and keyboard-accessible lightbox
- `cv.pdf` — downloadable two-page CV generated from the résumé details supplied in chat
- `cv-source.html` — editable, print-ready source used to generate `cv.pdf`
- `images/profile.png` — supplied professional portrait
- `images/photography/` — twenty supplied photos used in the album

The supplied CV included a residential address; it is intentionally omitted from the public download. The email, phone, and LinkedIn details in the site and CV are the ones provided in chat. Project reports and certificate files were not supplied, so no fabricated artifact links or credentials have been added.

## Preview

Open `index.html` in a browser, or run `py -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Before publishing

1. Verify current university status and update any changed academic details.
2. Review `cv-source.html`; regenerate `cv.pdf` if you edit it.
3. Add actual project reports, contributions, methods, tools, and findings where available. Keep concepts labeled as proposals.
4. Verify course titles, completion status, dates, and credential links.
5. Keep the files at the repository root; GitHub Pages is configured for the `main` branch root folder.

Published at `https://nihalth324.github.io/md.tasnemulhossain/`. Relative paths are used for GitHub Pages compatibility.
